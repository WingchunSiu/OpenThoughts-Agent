# Method attribution

The pipeline structure and portions of the synthesis/audit approach are adapted
from TerminalWorld:

- Source: <https://github.com/EuniAI/TerminalWorld>
- Revision inspected: `784698ba93735470ce1664bff2ec44bcd7b28e15`
- Upstream code license: Apache License 2.0
- Paper: *TerminalWorld: Benchmarking Agents on Real-World Terminal Tasks*
  (<https://arxiv.org/abs/2605.22535>)

This implementation uses OpenThoughts-Agent inference, Harbor task validation,
bounded shared environment profiles, and TaskTrove packaging. It contains no
TerminalWorld benchmark tasks, terminal transcripts, or benchmark canaries.
